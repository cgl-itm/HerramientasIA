# Proyectos destacados
A continuación se presentan los proyectos de aula destacados en el curso de Herramientas de IA.

* [NutriBot](https://github.com/cgl-itm/HerramientasIA/blob/main/Proyectos_Destacados/NutriBot.pdf): ChatBot para realizar sugerencias sobre alimentación.
* [MainteX](https://github.com/cgl-itm/HerramientasIA/blob/main/Proyectos_Destacados/Maintex%20Ia.pdf): Optimización predictiva y eficiencia mediante inteligencia artificial.
* [OptiRuta Med](https://github.com/cgl-itm/HerramientasIA/blob/main/Proyectos_Destacados/OptiRuta%20Med%20PdA-Optimizaci%C3%B3n%20Log%C3%ADstica%20Asistida%20por%20IA.pdf): Optimización logística aplicada a Medellín.
* [Optimización tráfico](https://github.com/cgl-itm/HerramientasIA/blob/main/Proyectos_Destacados/Proyecto%20De%20Aula%20-%20Movilidad.pdf): Monitorio y control del trafico por medio de aprendizaje por refuerzo.
